# BugsXie.github.io

Static snapshot of BugsXie's personal blog, generated by Hexo 6.3.0 with the Butterfly theme and prepared for deployment on GitHub Pages. Every page is pre-rendered HTML styled with CSS and enhanced with client-side JavaScript so it can be served directly without a build step.

## Project Highlights
- Landing page `index.html` provides hero banner, typed subtitle animation, sidebar widgets, announcement canvas, and quick metrics for articles, tags, archives, PV/UV counters, and last push date.
- Archive, tag, category, and friends-link listings live under dedicated directories (`archives/`, `tags/`, `categories/`, `link/`) with nested HTML pages already populated.
- Blog posts are pre-built into `post/` with full metadata blocks, sharing widgets, Busuanzi page-view hooks, and next-post navigation (two sample posts are included).
- Shared styling resides in `css/index.css`, which bundles Normalize.css, Butterfly theme variables, layout rules, widgets, and responsive tweaks; `css/var.css` is provided for downstream overrides.
- Client-side behavior is handled by `js/utils.js` (helper utilities, throttling, scrolling, animation helpers) and `js/main.js` (responsive navigation, sidebar toggles, dark mode switch, code-block toolbar, scroll interactions, and typed subtitle bootstrap). Optional language toggling stub lives in `js/tw_cn.js`, while search integrations are staged under `js/search/` for future activation.
- Assets in `img/` supply favicons, hero backgrounds, and fallback imagery used across the layout.
- Third-party enhancements are loaded from CDNs, including Font Awesome icons, Fancybox lightbox, Typed.js for banner typing, Busuanzi counters, and Butterfly's social-share bundle.

## Directory Overview
- `index.html` - home page, hero section, recent posts, tag cloud, archives, and global footer credits.
- `archives/` - archive index plus nested year/month listings (e.g. `archives/2023/04/index.html`).
- `categories/` - category landing page (currently empty state placeholder).
- `tags/` - tag overview and individual tag pages such as `tags/test-tag/index.html`.
- `post/` - full article pages (`Hello World`, `test`) with theme widgets and sharing UI.
- `link/` - friendly links page scaffold (no entries yet).
- `css/` - global stylesheet `index.css` and override stub `var.css`.
- `js/` - runtime scripts (`main.js`, `utils.js`, `tw_cn.js`) and search helpers under `js/search/` (`algolia.js`, `local-search.js`).
- `img/` - favicon, background artwork, and animated fallback GIFs used by the theme.

## Local Preview
The site is already production-ready. To preview locally, serve the root directory with any static file server, for example:

```bash
cd BugsXie.github.io
python -m http.server 4000
```

Then open `http://127.0.0.1:4000` in a browser. Hot reloading is not included; refresh the page after edits.

## Updating Content and Styles
1. **Direct static edits:** Update the generated HTML under `index.html`, `post/`, and other route directories, adjust styling in `css/index.css`, and tweak interactivity in `js/main.js` or `js/utils.js`.
2. **Regenerate via Hexo:** For large structural changes or new posts, use the original Hexo project (not part of this snapshot) to generate fresh static files with `hexo generate`, then replace the contents here.

When editing manually, keep references to external CDN assets intact unless you plan to self-host them under `/css/` or `/js/`.

## Deployment
- Push the contents of this repository to the `main` branch (or a `gh-pages` branch) of `bugsxie/bugsxie.github.io` on GitHub to publish automatically via GitHub Pages.
- Ensure that any additional assets are committed so relative links (e.g. `/img/...`) resolve correctly in production.
